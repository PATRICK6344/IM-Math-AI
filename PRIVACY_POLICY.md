# Privacy Policy for IM Pro Max

Last updated: 2026-10-08

## Overview

IM Pro Max is a local mathematics AI app designed to run on Android devices. The app stores some user and system data locally on the device to provide features such as:
- local knowledge storage
- mathematical explanations
- equation solving
- theory generation
- local AI model interaction

## Data collection

IM Pro Max does not intentionally collect personal data from users in the app itself.

The app may locally store:
- mathematical facts entered by the user
- local conversation history
- local knowledge database entries
- downloaded model files used for local AI inference

These files are stored on the device and are not transmitted to a remote server by default.

## Internet usage

The app may use internet access only for:
- downloading the local AI model on first use
- retrieving required dependencies if needed by the platform or environment

The app is designed to work offline after the model is downloaded.

## Third-party services

IM Pro Max does not require a remote backend for normal operation and does not intentionally share personal user data with third-party services.

## Security

Local data is kept on the device and protected by the standard Android app storage model. The app does not currently provide cloud sync or remote user accounts.

## Children’s privacy

This app is intended for educational and general use. It does not target children specifically, but it is suitable for general educational use.
